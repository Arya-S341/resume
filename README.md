# Arya S. Portfolio

This repository contains the personal portfolio of Arya S., a Computer Science and Engineering student specializing in Artificial Intelligence and Machine Learning at REVA University, with selected work, experience, technical skills, and certifications presented in an interactive web experience built with HTML, CSS, and JavaScript.

## Overview

This project showcases a clean, lightweight portfolio layout with:

- A modern landing page
- Project highlights or sections
- Responsive styling
- Simple interactive JavaScript behavior

## Files

- `index.html` — main page structure
- `style.css` — styling and layout
- `script.js` — interactive functionality

## Highlights

- Animated hero section with an interactive typing effect
- Responsive sections for experience, projects, skills, and certifications
- GitHub and Credly links for featured work and credentials

## How to Run

1. Open `index.html` in a browser, or
2. Use a local web server in the project folder, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customization

Edit the HTML content to add your own name, bio, projects, and contact information. Update the CSS to adjust colors, spacing, and layout styling.
